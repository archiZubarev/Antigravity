# Анлокер на macOS

Та же программа, что на Windows и Linux: то же окно, те же переключатели, та же карточка «работает ли Antigravity». Проверена на Apple Silicon. Под Intel собирается с флагом `--universal`, но эта сборка пока не проверялась ни разу.

## Сборка

```bash
macos/build.sh
```

Результат появится в `dist/`: `AG Unlocker.app` и zip с ним. Если нужен один файл сразу под Apple Silicon и Intel, добавьте `--universal`. Для этого сначала поставьте `rustup target add aarch64-apple-darwin x86_64-apple-darwin`.

Подпись ad-hoc, Developer ID нет. Поэтому копию, скачанную из интернета, первый раз открывают через правый клик → «Открыть» или через «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

## Первый запуск

1. Откройте `AG Unlocker.app` и нажмите «Включить всё».
2. macOS не даёт одной программе менять другую, пока это не разрешено. Анлокер сам откроет «Системные настройки → Конфиденциальность и безопасность → Управление приложениями». Включите там «AG Unlocker» и нажмите «Включить всё» ещё раз.
3. Antigravity при этом закроется. Откройте его снова: так он подхватит переменную прокси. Затем напишите что-нибудь в чат.

Пароль администратора нужен только в одном случае: если Antigravity установлен от имени root (из `.pkg`, а не перетаскиванием в «Программы»). Тогда анлокер покажет системный запрос.

## Что меняется в системе

- **`Antigravity.app/Contents/Resources/bin/language_server`** и **`~/.local/bin/agy`**. В них заменяются те же две строки, что на Windows. После этого файл заново подписывается ad-hoc: без подписи macOS на Apple Silicon не запустит изменённый бинарник. Подпись Google на остальном приложении не трогается, поэтому автообновление Antigravity продолжает работать.
- **`~/Library/LaunchAgents/com.agunlocker.proxy.plist`**. Это локальный прокси на `127.0.0.1:53129`, запускается при входе в систему и перезапускается после сбоя. Копия программы для него лежит в `~/Library/Application Support/AGUnlocker/`, там же журнал и настройки.
- **Переменная `AG_LS_PROXY`** в окружении сеанса (`launchctl setenv`). Её читает только пропатченный language server, остальные программы её не видят. После перезагрузки её выставляет служба.

Ничего из этого не требует root и не трогает системный DNS.

## VPN

Если VPN выходит в стране без ограничений, служба использует его как маршрут. Свои запросы к сервисам разблокировки она в это время отправляет мимо туннеля, через провайдера: эти сервисы отвечают только российским адресам. Настраивать ничего не нужно.

## Свои серверы вместо сервисов разблокировки

В разделе «Для опытных» в поле «Свой HTTP-прокси» можно указать до четырёх своих прокси через пробел, в формате `https://логин:пароль@сервер:порт`. Они пробуются по порядку: если первый не ответил, это же соединение уходит на второй. При схеме `https://` анлокер поднимает TLS до самого прокси и проверяет его сертификат, так что пароль и имя хоста по сети открытым текстом не идут.

Переключатель «Только свои серверы» выключает всё, что идёт через чужие сервисы. Анлокер перестаёт обращаться к DNS-сервисам разблокировки (dns-ai.ru, geohide.ru, comss.one, DoH на dns.dns-ai.ru) и соединяться с адресами, которые они выдают. Остаются ваши прокси и ваш VPN.

Чтобы прокси подошёл, на сервере должно быть разрешено:
- `CONNECT` к `cloudcode-pa.googleapis.com:443` и `daily-cloudcode-pa.googleapis.com:443`, остальное можно запретить;
- логин и пароль в первом же `CONNECT` (`Proxy-Authorization: Basic`). Поэтому подойдёт и прокси, который на чужие запросы не отвечает кодом 407: например, Caddy forwardproxy с `probe_resistance`.

## Чего пока нет

- **Автопатча после обновления Antigravity.** Обновление заменяет приложение целиком, и патч слетает. Карточка это покажет, тогда нажмите «Включить всё» ещё раз.
- **DNS-слоя.** На Windows он позволяет не перезапускать Antigravity после включения обхода. На маке после «Включить всё» Antigravity нужно открыть заново.

## Откат

Выключите переключатели в окне. Выключение патча возвращает строки на место. Подпись у файла остаётся ad-hoc, а не Google, пока Antigravity не обновится или не будет переустановлен. Выключение обхода удаляет LaunchAgent, копию программы и переменную.
